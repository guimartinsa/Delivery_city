# Delivery City

Site inicial 100% funcional com dados mockados para validação do fluxo de delivery.

## O que já funciona

- Seleção de loja.
- Exibição de cardápio por loja.
- Carrinho com adição e remoção de itens.
- Cálculo de total em tempo real.
- Finalização de pedido com nome do cliente.
- Histórico de pedidos mockados com status de WhatsApp simulado.

## Publicação no GitHub Pages

1. Suba os arquivos para a branch principal.
2. Em **Settings > Pages**, configure para publicar a partir da raiz (`/root`) da branch.
3. A página principal será `index.html`.

## Estrutura

```text
index.html
styles.css
app.js
```
